# Changelog

## Unreleased — 0.23.1

Initial public release candidate. Requires Obsidian 1.8.7 or later.

- Open today's existing daily note with configurable folder and date formats.
- Reuse existing main-editor tabs for daily notes and file shortcuts.
- Configure file titles and subtitles from text, file names, or frontmatter properties.
- Display unfinished task counts and progress rings, with optional Tasks status support.
- Organize items with visibility controls, ordering, separators, and reusable presets.
- Use built-in icons or the optional Custom Icons integration.
- Follow Obsidian's interface language in Simplified Chinese or English.
- Query the active view through the public Obsidian API.

Desktop acceptance testing has passed on macOS with Obsidian 1.14.5. Mobile acceptance testing is pending. This candidate has not yet been published to the community directory.
