# Today Sidebar

在 Obsidian 左侧栏集中打开今日日记和常用文件。你可以添加文件入口、用分隔线分组，并在入口旁显示任务数量或完成度。

[English](README.md)

## 主要功能

- 根据指定文件夹和日期格式，打开当天已有的日记。
- 添加库内文件入口，包括非 Markdown 文件；目标已在主编辑区打开时复用原标签。
- 用普通文本、文件名或文件属性显示主副标题；属性标题过长时可设置简称，不改动笔记。
- 显示目标笔记的未完成任务数，或用完成度饼图替代图标；文件条目与今日日记均可使用。
- 拖动或通过上移／下移按钮排序，隐藏条目、添加分隔线，保存可复用的预设。
- 跟随 Obsidian 主题和界面语言：中文使用简体中文，其余语言使用英文。

## 环境与发布状态

需要 **Obsidian 1.8.7 或更新版本**，当前发布版本为 [**0.24.0**](https://github.com/Chartreuse310/obsidian-today-sidebar/releases/tag/0.24.0)。

桌面端已在 macOS、Obsidian 1.14.5 上完成验收；移动端也已完成验收，未发现问题。基本功能不需要安装其他第三方插件。

## 手动安装

从 [0.24.0 发布页](https://github.com/Chartreuse310/obsidian-today-sidebar/releases/tag/0.24.0)下载 [ctz-today-sidebar.zip](https://github.com/Chartreuse310/obsidian-today-sidebar/releases/download/0.24.0/ctz-today-sidebar.zip)，其中包含运行文件和 LICENSE。官方目录提交是下一步，目前请手动安装。

1. 解压下载的 ZIP，得到 `ctz-today-sidebar` 文件夹。
2. 将整个文件夹放入库的插件目录（通常为 `.obsidian/plugins/`），路径应类似 `.obsidian/plugins/ctz-today-sidebar/main.js`。
3. 打开 Obsidian **设置 → 第三方插件**，启用 **Today Sidebar**。如果尚未列出，重启 Obsidian 后再次查看。
4. 选择左侧栏的日历标签，或在命令面板执行 **Today Sidebar: 显示边栏**。

手动更新时替换同名的三个运行文件和 LICENSE，再在 Obsidian 中重新加载插件；保留已有的插件设置文件。

## 开始使用

打开 **设置 → Today Sidebar**，选中 **今日日记**。

按你的日记存放方式填写 **日记文件夹** 和 **文件名日期格式**。默认目标为 `00-journal/YYYY-MM-DD.md`，使用设备本地日期。例如，2026 年 10 月 26 日对应 `00-journal/2026-10-26.md`。文件夹留空表示库根目录；日期格式无需填写 `.md`，编辑区会预览实际路径。

**副标题显示** 在日期与当天日记的未完成任务数之间单选。日期默认 `YYYY-MM-DD ddd`，星期名称使用英文；日期格式留空可隐藏副标题，不改变打开路径。改选未完成任务数后，副标题改为该数量的统计结果，日期格式会保留，切回日期即可恢复。

插件只打开已有文件。当天日记不存在时，会提示预期路径，你可以沿用自己的日记工作流创建它。

### 文件入口与布局

点击 **添加 → 文件**，在 **文件地址** 选择库内文件，再设置主标题、副标题和图标。编辑会即时保存。

点击眼睛按钮可隐藏条目并保留配置；拖动把手或使用上移／下移按钮调整顺序。分隔条目支持单线、虚线和空白占位。删除条目只移除入口，保留目标文件；今日日记只能隐藏，不能删除。

文件和分隔条目可 **保存为预设**，之后从添加菜单创建副本。预设和已添加副本各自独立，后续修改互不影响。

## 任务数量与完成度

选中文件条目或今日日记，设置 **副标题显示 → 未完成任务数**，或 **图标显示 → 完成度饼图**。两者只统计目标 Markdown 文件，包含嵌套任务。今日日记的目标是按日期格式解析出的当天文件，因此副标题与饼图会随日期和当天日记内容更新。

没有 Tasks 配置时，未勾选任务计为未完成，`x`/`X` 计为完成。库中已有 Tasks 状态配置时，待办、进行中、挂起计为未完成，完成计为已完成；取消、非任务与未知状态不计入。完成度为“已完成 /（未完成 + 已完成）”，不应用 Tasks 查询结果或全局过滤器。

`0` 表示没有未完成任务，`…` 表示等待元数据，`—` 表示无法统计。没有可统计任务或统计不可用时，饼图回退为保存的普通图标。

## 可选集成

**Custom Icons 插件：** 无需此插件也能使用 Obsidian 内置图标。启用兼容版本后，点击 **按钮图标** 输入框旁的预览图标即可打开选择器。提供方不可用、接口不兼容或图标无法绘制时，使用内置图标；原图标 ID 会保留，恢复可用后可继续显示。

**Tasks 插件：** 使用任务数或完成度时，若库中存在 Tasks 状态配置，Today Sidebar 会只读该配置，无需 Tasks 正在运行，也不会改动其设置。缺少配置时使用标准复选框规则；配置无法读取或格式不支持时，统计显示不可用。兼容格式以 Tasks 8.4.0 为依据。

## 数据与设置

插件在库的插件配置目录保存自身设置，读取目标文件元数据及任务状态用于显示，并在点击入口时打开文件。插件不创建日记或修改笔记正文；删除入口或预设也不会删除目标文件。旧版本设置会在迁移时保留。

### 隐私与集成边界

Today Sidebar 自身不发起网络请求，不包含遥测、广告、付费或账号要求。文件建议使用库内路径，文件属性和任务数量使用 Obsidian 元数据缓存；自身设置通过 Obsidian 保存，启用任务统计时读取同一库内的 Tasks 配置。正常使用时不读取库外文件。

Custom Icons 是另行安装的可选插件，打开其选择器会将操作交给该插件；图标下载与可能的网络访问由该插件负责。Today Sidebar 通过 Obsidian 非公开的插件查找接口取得其 API，检查契约版本 1 与所需方法，不可用时回退内置图标。
